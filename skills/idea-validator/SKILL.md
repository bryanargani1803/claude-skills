# Idea Validator

## When to use
Use this skill when the user has a product idea and wants to know if it will sell.

## Ask the user for (only what is missing)
- Product idea
- Target buyer
- Planned price

## Process
1. Restate the idea as a specific outcome for a specific buyer.
2. Run a checklist: painful problem? buyers already paying? reachable audience? clear format? can deliver in under 2 weeks?
3. List the 3 biggest risks and how to test each in 48 hours (pre-sale post, free version, waitlist).
4. Give a go / tweak / drop verdict.

## Output
A validation scorecard, risks with 48-hour tests, and a verdict.

## Rules
- Be honest - a 'drop' verdict saves the user weeks.
- Suggest a narrower angle before dropping an idea.
- If key inputs are missing, ask at most 3 short questions, then proceed with sensible defaults and state them.
- Write in plain, human language. Avoid AI clichés (delve, unlock, elevate, game-changer).
