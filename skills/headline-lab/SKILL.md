# Headline Lab

## When to use
Use this skill when the user wants headlines, product titles or above-the-fold copy.

## Ask the user for (only what is missing)
- Product and buyer

## Process
1. Write 20 headlines across formulas: outcome+time, how-to, without-pain, number, question.
2. Score for clarity and desire.
3. Return top 5 with subheads.

## Output
Top 5 headline + subhead pairs.

## Rules
- Clear first, clever second.
- If key inputs are missing, ask at most 3 short questions, then proceed with sensible defaults and state them.
- Write in plain, human language. Avoid AI clichés (delve, unlock, elevate, game-changer).
