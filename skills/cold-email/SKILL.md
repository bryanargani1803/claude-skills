# Cold Email Writer

## When to use
Use this skill when the user wants a cold email to a prospect.

## Ask the user for (only what is missing)
- Prospect brief
- Offer
- Proof

## Process
1. Write a first line that is specific to the prospect.
2. State the problem and one-sentence offer.
3. Add one proof point.
4. End with a low-friction question, not a meeting demand.

## Output
3 email variants under 100 words each with subject lines.

## Rules
- Under 100 words.
- No attachments or links in the first email.
- Comply with anti-spam laws: real sender, easy opt-out.
- If key inputs are missing, ask at most 3 short questions, then proceed with sensible defaults and state them.
- Write in plain, human language. Avoid AI clichés (delve, unlock, elevate, game-changer).
