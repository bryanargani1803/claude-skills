# Scroll-Stopping Hook Writer

## When to use
Use this skill when the user needs opening lines for posts, threads, videos or emails, or says their posts get no reach.

## Ask the user for (only what is missing)
- The post topic or draft
- Platform
- Target reader

## Process
1. Identify the single most surprising or useful promise in the topic.
2. Write 15 hooks across 5 formulas: Bold claim, Specific number, Mistake callout, Before/after, Curiosity gap.
3. Score each hook 1-10 for clarity, specificity and curiosity.
4. Return the top 5 with the reason each works.
5. Offer a rewritten first 2 lines of the post using the best hook.

## Output
Top 5 hooks ranked, each under 15 words, with a one-line reason, plus the rewritten opening.

## Rules
- No clickbait the post cannot deliver on.
- Use numbers and concrete nouns over adjectives.
- Hooks must make sense with zero context.
- If key inputs are missing, ask at most 3 short questions, then proceed with sensible defaults and state them.
- Write in plain, human language. Avoid AI clichés (delve, unlock, elevate, game-changer).
