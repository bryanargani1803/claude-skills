## Install (2 minutes)

**Claude app (web, desktop, mobile)**
1. Settings → Capabilities → turn on **Skills**.
2. Zip a skill folder (e.g. `skills/anti-slop`) and click **Upload skill**.
3. Ask Claude normally. It picks the skill by itself.

**Claude Code**
```bash
git clone https://github.com/bryanargani1803/claude-skills
cp -r claude-skills/skills/* ~/.claude/skills/
```

**ChatGPT / Gemini**: open any `SKILL.md` and paste the Process + Rules into a chat, Custom GPT or Gem.
